# Cursor-course-evidence

Repositorio que documenta las evidencias y prácticas del curso de desarrollo asistido con IA a través de Cursor.

## Objetivo del curso

El objetivo central del curso es que el participante domine la inteligencia artificial como copiloto de desarrollo. Se aborda la estructuración de proyectos, la definición de contratos técnicos y el contexto necesario para que herramientas como Cursor generen código funcional, escalable y alineado a estándares de calidad.

El enfoque es práctico: transitar de la escritura manual de código a la orquestación de agentes para construir aplicaciones completas, desde el backend con FastAPI y Docker hasta interfaces modernas con Next.js, con Cursor IDE como entorno principal.

## Objetivo del proyecto

**Platziflix** es una plataforma online de cursos simple y directa. Cada curso contiene clases con descripciones básicas. Se trata de una implementación minimalista enfocada en la funcionalidad core de distribución de contenido educativo.

El proyecto se mantiene deliberadamente simple, sin features adicionales complejas. En este repositorio se desarrolla primero la API backend (FastAPI, PostgreSQL, Docker) y, en etapas posteriores, las capas de frontend y mobile descritas en [labs/day-01/Backend/README.md](labs/day-01/Backend/README.md).
